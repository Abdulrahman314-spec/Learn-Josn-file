01 Anatomy of a JSON file

Every JSON document is built from the same few pieces.

{
  "name": "Abdulrahman",
  "age": 27,
  "skills": ["git", "json"]
}
  • { } — an object: a set of key/value pairs
  • "key" — always text, always double-quoted
  • : — separates a key from its value
  • , — separates entries, never after the last one
  • [ ] — an array: an ordered list of values

02 Data types

JSON supports exactly six value types — nothing else.

05 Common mistakes

  • ✕{ "a": 1, }trailing comma before the closing brace
  • ✕{ 'a': 1 }single quotes are not valid JSON
  • ✕{ a: 1 }unquoted keys are not allowed
  • ✕{ "a": 1 // note }comments are not supported in JSON

06 Parsing in code

Turn the text on disk into a usable object, and back again.

const text = fs.readFileSync("data.json");
const data = JSON.parse(text);       // text → object
JSON.stringify(data, null, 2);       // object → text

07 Bonus: JSON Schema

Optional — describes the shape your JSON must follow, so it can be validated automatically.

{
  "type": "object",
  "required": ["name"]
}
